# Vansh Nagpal — Portfolio

An interactive portfolio for Vansh Nagpal, initially built as an iPad Classic-inspired web experience.

## Run locally

```bash
npm install
npm run dev
```

## Verify production build

```bash
npm run build
```

## Stack

- Next.js
- React
- TypeScript

The next design iteration will replace the initial horizontal interface with a portrait, vector-rendered iPod Classic experience.
