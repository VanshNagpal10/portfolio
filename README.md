# Vansh Nagpal — Classic Portfolio

A portfolio presented through a tactile, portrait classic-player interface.

## Development

Install the dependencies and start the app:

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

## Controls

- Drag around the click wheel or use the arrow keys to navigate.
- Press the centre button or `Enter` to open an item.
- Press `MENU`, `Escape`, or `M` to return.
- Enable the screen’s speaker button for subtle click sounds.
